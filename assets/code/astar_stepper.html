How A* works: Same as Dijkstra, but with one change: instead of visiting the blue cell with the lowest cost-so-far (g), we visit the one with the lowest f = g + h, where g = cost from S to this cell (known), and h = estimated cost from this cell to G (heuristic guess). This makes the search prefer cells that are closer to the goal, avoiding wasted exploration.
